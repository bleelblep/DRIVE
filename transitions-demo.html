⚙️ How It Works

1. Link Interception

When you click a link, JavaScript intercepts it and fetches the new page content via AJAX:

document.addEventListener('click', (e) => { const link = e.target.closest('a'); if (link && link.hostname === window.location.hostname) { e.preventDefault(); navigate(link.href); } });

2. View Transition API

The View Transitions API handles the smooth morphing automatically:

const transition = document.startViewTransition(() => { // Update the page content document.body.innerHTML = newContent; }); await transition.finished;

3. CSS Animations

CSS defines which elements should morph and how:

/* Define shared elements */ .logo-light, .logo-dark { view-transition-name: logo; } /* Customize animations */ ::view-transition-old(root), ::view-transition-new(root) { animation-duration: 400ms; animation-timing-function: cubic-bezier(0.4, 0.0, 0.2, 1); }

🌐 Browser Support

✅ Chrome 111+ ✅ Edge 111+ ✅ Opera 97+

Graceful degradation: For browsers that don't support the View Transitions API, the site falls back to a simple fade transition. Users with "reduced motion" preferences get instant navigation with no animations.
