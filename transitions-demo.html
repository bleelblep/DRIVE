Features Demonstrated

View Transitions API

Modern Browser Support

Uses the native View Transitions API in Chrome/Edge 111+ for smooth, performant animations with automatic fallback for other browsers.

document.startViewTransition(() => {
  // Update page content
});
Shared Elements

Morphing Animations

Elements like the logo and dark mode toggle smoothly morph between pages, maintaining visual continuity.

element.style.viewTransitionName = 'logo';
FLIP Technique

Performant Transforms

Uses GPU-accelerated transforms and opacity for smooth 60fps animations without layout recalculation.

/* GPU-accelerated properties */
transform: translateX(30px);
opacity: 0;
Accessibility

Respects User Preferences

Automatically reduces or disables animations for users who prefer reduced motion.

@media (prefers-reduced-motion) {
  animation-duration: 0.01ms;
}

How It Works

  1. 1.
    Link Click Intercepted: JavaScript captures all internal link clicks before navigation occurs.
  2. 2.
    Page Fetched: The new page is fetched asynchronously in the background.
  3. 3.
    Transition Started: View Transitions API creates snapshots of shared elements.
  4. 4.
    Content Updated: DOM is updated with new page content.
  5. 5.
    Animation Plays: Browser automatically animates between old and new states using CSS-defined transitions.

Add to Your Pages

To enable smooth transitions on any page, simply add these two lines before the closing </body> tag:

<link rel="stylesheet" href="page-transitions.css">
<script src="page-transitions.js"></script>

That's it! The script will automatically intercept navigation and apply smooth transitions.
