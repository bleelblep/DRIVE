What Just Happened?

When you navigated from Page 1 to this page:

  1. The browser captured a snapshot of Page 1
  2. The browser loaded this page (Page 2)
  3. The browser captured a snapshot of Page 2
  4. The browser animated between the two snapshots
  5. Elements with matching view-transition-name morphed smoothly

All of this happened automatically thanks to the CSS rule: 

@view-transition {
    navigation: auto;
}
