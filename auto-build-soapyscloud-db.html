Automated SoapysCloud Database Builder

How to Use

Method 1: Parse Directory Listing HTML

  1. Visit your soapysdrive.com directory page
  2. Right-click → "View Page Source" or press Ctrl+U
  3. Copy all the HTML
  4. Paste it in the text area below
  5. Set the base URL and collection
  6. Click "Parse & Generate Database"

Method 2: Paste File List

  1. Copy file names from directory (one per line)
  2. Paste in "Simple File List" mode
  3. Provide URLs manually or use base URL pattern
