The simplest way to add smooth transitions to multi-page applications

How It Works

Cross-document view transitions use a simple CSS rule to enable smooth animations between page navigations:

@view-transition { navigation: auto; }

That's it! No JavaScript required. The browser automatically handles the transition animation when you navigate between pages.

Custom Element Morphing

You can also make specific elements morph smoothly between pages by giving them the same view-transition-name:

.demo-box { view-transition-name: demo-box; }

Elements with matching names will smoothly morph into each other during page transitions!

Browser Support

Cross-document view transitions are supported in:

  • Chrome 126+
  • Edge 126+
  • Opera 112+

For browsers that don't support this feature, pages will load normally without transitions.

JavaScript vs CSS-only

JavaScript Approach

  • ✓ Works in more browsers (Chrome 111+)
  • ✓ More control over behavior
  • ✗ Requires intercepting clicks
  • ✗ Must handle history/routing
  • ✗ More complex code

CSS-only Approach

  • ✓ One line of CSS
  • ✓ No JavaScript needed
  • ✓ Browser handles everything
  • ✓ Works with regular navigation
  • ✗ Newer feature (Chrome 126+)
